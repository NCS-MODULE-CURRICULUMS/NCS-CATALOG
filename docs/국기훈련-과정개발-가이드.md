# 국기(국가기간·전략산업직종)훈련 과정개발 가이드

> 조사일 2026-09-16 · 출처: 직업능력심사평가원(ksqa.or.kr), NCS(ncs.go.kr), 고용24(work24.go.kr)
> ⚠️ **훈련시간·NCS 적용비율·훈련비 단가 등 수치 기준은 매년 계획공고로 바뀝니다.**
> 반드시 KSQA `당해년도 계획공고`와 `소통마당 > 자료실 > 집체(통합)훈련심사 자료실 설명회 자료집`으로 최신값을 확인하세요.

## 1. 국기훈련이 어디에 속하는가

국기훈련은 KSQA의 **집체(통합)훈련심사** 대상 4종 중 하나입니다.

| 훈련대상 | 훈련사업 | 약어 |
|---|---|---|
| **실업자** | **국가기간·전략산업직종훈련** | **실업자 국기** |
| 실업자 | 일반계좌제훈련 | 실업자 계좌제 |
| 재직자 | 일반계좌제훈련 | 재직자 계좌제 |
| 재직자 | 사업주직업능력개발훈련(위탁) | 사업주 위탁 |

즉 **과정을 "개발"한다는 것 = 통합심사를 통과할 수 있는 훈련과정 설계서를 만든다**는 뜻입니다.
KDT(K-디지털 트레이닝)·기업맞춤형국기는 **정책특화심사**로 트랙이 다릅니다(KSQA ARS 3번).

## 2. 신청 자격 (선행조건)

`근로자직업능력개발법` 시행령 제12조·제17조·제22조에 따른 시설/기관이어야 합니다.
- 직업능력개발훈련시설
- 「고등교육법」 제2조 학교
- 「평생교육법」에 따른 평생교육시설
- 「학원법」 제2조의2 평생직업교육학원 등

> **훈련기관등록·관리시스템에 "실시가능직종"을 먼저 등록해야 합니다. 등록 안 된 직종은 과정 신청 자체가 불가.**
> → 우리가 다룰 직종(20.정보통신 하위 세분류)을 먼저 등록 직종에 올려야 합니다.

## 3. 심사 기준 = 과정 설계의 체크리스트

KSQA 집체(통합)훈련심사는 네 덩어리입니다. **이 순서가 곧 과정개발 순서입니다.**

### ① 직종분류검토
> 훈련내용과 선택한 **NCS 직종 간의 연관성**을 검토하여 적정한 직종으로 연계
> → 결과가 **NCS직종단가 및 훈련실적 산정**에 영향

**가장 먼저 결정할 것: 이 과정을 어느 NCS 세분류에 붙일 것인가.**
잘못 붙이면 훈련비 단가와 실적 산정이 통째로 달라집니다.
예) "클라우드 보안 과정"을 `20010206 보안엔지니어링`에 붙일지 `20010612 클라우드 보안 관리·운영`에 붙일지 — 교과 구성이 달라집니다.

### ② 기본요건 심사 → 적합/부적합 (탈락 게이트)
- 훈련기관 신청자격
- 과정 편성 기본요건
- **NCS 적용 필수기준** ← NCS 적용은 선택이 아니라 의무

### ③ 훈련과정 적합성 심사
| 항목 | 내용 |
|---|---|
| 신청제한분야 | 국가지원 필요성·직업훈련 실효성 등으로 제한분야 해당 여부 |
| **과정적정성** | 훈련내용·방법·교강사·시설·장비 **전 항목**의 적정성(적부) + 우수성(점수) |
| 성과적정성 | (실업자 계좌제) 직종별 수료 5인 이상 과정 대상 |
| **산업·지역인력수요적정성** | **(실업자 국기)** 산업·지역 수요에 따른 선정규모를 고려해 선정범위 내 과정 성과 판단 |

> **국기 고유 관문이 ④번입니다.** 과정이 아무리 좋아도 **해당 권역·직종의 선정규모(쿼터)** 밖이면 떨어집니다.
> → KSQA가 매년 내는 **`운영 국가기간전략산업직종훈련 권역·직종별 (선정규모) 공고`**를 과정 기획 *전에* 봐야 합니다.

### ④ 훈련비 심사
훈련비 실비 지원 신청 과정 대상. 고급/특화과정 여부 심의 + 예산비목·산정기준 검토 → 정부승인 훈련비 결정.

### 신청 경로
`HRD-Net(심사평가시스템) 접속 > 통합심사 > 심사공모조회 > 해당 회차 선택`

## 4. NCS 기반 과정 편성 실무 절차

NCS가 제공하는 3종 산출물을 이 순서로 씁니다.

```
NCS 분류체계 (대>중>소>세분류)
      ↓ 직종 선택
NCS 기반 훈련기준            ← ncs.go.kr에서 세분류별로 제공 (전 직종 훈련기준 제공)
      ↓ 능력단위/능력단위요소 선택
훈련과정 편성표 (교과목)
      ↓
NCS 학습모듈 + 평가도구      ← ncs.go.kr 학습모듈, 평가도구 활용 매뉴얼
```

**단계별로 할 일**

1. **직무 선정** — 목표 취업직무 → NCS 세분류 1개(주) + 보조 세분류 확정
2. **직무모델링** — 산업체 요구·채용공고 분석으로 실제 수행직무 정리 (심사에서 "산업현장성"으로 봄)
3. **능력단위 선정** — 훈련기준의 능력단위 중 취사선택. 선택 근거를 문서로 남길 것
4. **능력단위요소 → 교과목 매핑** — 능력단위 1개 = 교과목 1개가 기본, 쪼개거나 묶을 수 있음
5. **훈련시간 산정**
   - 훈련시간에 **포함**: 온라인 포함 수업시간, 수업 중 과제 수행·피드백, 평가시간
   - 훈련시간에서 **제외**: 선수학습, 개인학습, 복습, 시험준비
   - 재직자 과정에서 능력단위 내 일부 요소만 편성하면 **능력단위 표준훈련시간 내 자율 편성**
6. **NCS 적용비율 산정** — 전체 훈련시간 중 NCS 능력단위 기반 시간 비중 (기본요건 심사 항목)
7. **평가도구 설계** — 능력단위별 평가방법(포트폴리오/작업장평가/서술형/사례연구 등) + 평가기준
8. **교강사·시설·장비 매칭** — 과정적정성 심사 항목. 능력단위별로 필요한 장비를 역산
9. **편성표 작성 → HRD-Net 제출**

## 6. 연간 캘린더(과정 기획자 기준)

1. KSQA `권역·직종별 선정규모 공고` 확인 → 우리 직종에 쿼터가 있는지
2. KSQA `당해년도 계획공고` + 설명회 자료집 → 그해 심사기준 수치 확보
3. HRD-Net 심사평가시스템 `심사공모조회`로 회차 확인
4. 편성표 작성 → 신청 → 심사 → 선정
5. 고용24에 과정 게시 → 모집
